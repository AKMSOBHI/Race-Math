# اسم اللعبة: سباق الرياضيات

## وصف اللعبة
لعبة تعليمية تفاعلية تهدف إلى مساعدة الطلاب على تحسين مهاراتهم في الحساب (الجمع، الطرح، الضرب، القسمة) من خلال بيئة ممتعة في الفضاء مع الكواكب.

## الهدف من اللعبة
- تقوية مهارات الرياضيات بطريقة ممتعة.
- تحفيز الطلاب على التنافس الإيجابي.
- توفير تعليم مرئي وسماعي يشجع الفهم السريع.

## طريقة اللعب
- تظهر أسئلة داخل مربع.
- اللاعب يختار الإجابة الصحيحة.
- عند نهاية المستوى، تظهر لوحة النتائج.

## تطوير
تم تطوير اللعبة باستخدام HTML/CSS/JavaScript على منصة Replit.
