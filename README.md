## حول المشروع

سباق الرياضيات هو لعبة تعليمية تفاعلية تساعد الطلاب على تعلم وممارسة العمليات الحسابية الأساسية (الجمع، الطرح، الضرب، القسمة) بطريقة ممتعة وتنافسية.

## المزايا الرئيسية

- واجهة مستخدم سهلة الاستخدام ومصممة للطلاب
- وضع اللعب الفردي ووضع المنافسة المتعددة
- نظام نقاط ومستويات متقدمة
- مراحل متنوعة لمختلف العمليات الحسابية
- لوحة تحكم للمعلم لمتابعة تقدم الطلاب
